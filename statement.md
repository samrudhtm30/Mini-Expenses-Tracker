# Expense Tracker. Project Statement

## Problem Statement
Many people want a way to keep track of their daily spending. Without a record it's hard to look back at individual purchases compare how much is spent in different areas or find out the total amount spent. This project builds a command-line expense tracker that helps users enter expenses and view summaries of their spending.

## Scope of the Project
This is a menu-driven Python program designed to manage expense records during one session. Each expense includes a date, category, description and amount. Users can add entries view them summarize by category search by category calculate totals and delete items.

The project stays focused on single-user tracking in the terminal. It does not save data to files or databases. Does it support budgets, charts, currency conversion or multiple users.

## Target Users
- Individuals who want to track spending without using complex apps.
- Students learning Python basics like functions, lists, dictionaries, loops, input handling and the `tabulate` library.
- Beginners who want to see how a small command-line tool can organize and display data.

## High-Level Features
- **Add an expense:** Enter the date category, description and amount.
- **Display expenses:** Show all entries in a formatted table.
- **Category summary:** List total spending per category.
- **Calculate total expenses:** Add up all amounts.
- **Search by category:**. Show all expenses in a specific category.
- **Delete an expense:** Remove an entry by selecting its index from the list.
- **Menu-based navigation:** Choose actions, from a menu or exit the program.
